# ResortHub 🏝️

**Discover Your Perfect Stay in Kannur, Kerala.**

ResortHub is a full-stack MERN web application designed to help users explore resorts, beach stays, and nature retreats in Kannur, Kerala. It features resort discovery, room details, user authentication, and admin management.

## ✨ Features

- Explore and search resorts.
- View resort details, rooms, and amenities.
- User registration and login.
- Secure authentication using JWT and HttpOnly cookies.
- Admin access to create, update, and delete resort listings.
- Responsive React-based user interface.

## 🛠️ Tech Stack

- **Frontend:** React, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Sankarxn/ResortHub.git
cd ResortHub
npm install
```

Configure the environment variables in the backend using `server/.env.example`, then install and run the backend:

```bash
cd server
npm install
npm run dev
```

In a separate terminal, run the frontend:

```bash
cd client
npm install
npm run dev
```

Configure your MongoDB connection and other required environment variables before starting the application.
